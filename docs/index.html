1. Overview

A multimodal Indian Sign Language system designed for real-time edge processing and accessibility.

Engineering Mission

The current baseline recognizes isolated fingerspelling characters and digits in real time. These recognized characters can be accumulated into text. Word-level temporal sign recognition is part of the next development stage.

Alphabet fingerspelling is a fundamental accessibility layer for names, numbers, and technical terms, but is distinct from native ISL lexical word signs and continuous signing.

Production Design Principles

  • Zero Cloud Inference for Vision: MediaPipe and static neural classification run 100% on the local CPU.
  • State-Machine Stabilization: Guaranteed single-character emission during held gestures.
  • Resilient Language Layer: Gemini 3.5 Flash Lite translation with automatic offline lexicon fallback.

2. Current Baseline (v1 Release)

Verified capabilities implemented in the active codebase.

Current baseline: fingerspelling recognition A-Z and 1-9.

The active production model is a deep Multi-Layer Perceptron (MLP) trained on 63-dimensional normalized single-hand coordinates. It recognizes 35 static sign classes with 99.36% test accuracy and sub-2ms CPU inference latency.

Current production inference model: Static MLP classifier. Temporal word-sign recognition is a planned future phase. Continuous ISL signing is planned future work and is not part of Baseline v1.

Scope Boundary: Word-level temporal sign recognition and continuous signing are future development stages and are not included in Baseline v1.

3. System Architecture

End-to-end dataflow from camera ingestion to speech synthesis.

1

Camera Ingestion

Captures video frames via browser WebRTC or WebSocket at 30 FPS.

2

MediaPipe Hands

Locates 21 3D single-hand landmarks $(x, y, z)$ with on-device sub-15ms processing.

3

63D Geometric Normalization

Centers coordinates at the wrist origin $(0, 0, 0)$ and scales by max Euclidean distance for scale and translation invariance.

4

Static MLP Classifier

Computes softmax probabilities across 35 fingerspelling classes (`1`–`9`, `A`–`Z`).

5

Temporal Stabilizer & State Machine

Requires 60% majority consensus over a 6-frame rolling window; emits a sign exactly once and enters cooldown.

6

Text Buffer Accumulator

Manages live character accumulation with append, space, backspace, and clear operations.

7

Multilingual Translation & TTS

Translates into Telugu, Hindi, Tamil, Kannada, and Marathi via Gemini 3.5 Flash Lite with local offline pyttsx3 speech audio.

4. Current Features

Empirically verified capabilities backed by 49 automated unit and acceptance tests.

35 Fingerspelling Classes

High-precision recognition of digits 1-9 and letters A-Z at 99.36% test accuracy.

Debounce State Machine

Eliminates character duplication bugs by enforcing neutral-state transitions before new emissions.

5 Indian Languages

Native support for Telugu (`te`), Hindi (`hi`), Tamil (`ta`), Kannada (`kn`), and Marathi (`mr`).

Zero Cloud Vision

All computer vision and landmark classification run entirely on standard commodity CPUs.

Local Speech Synthesis

Offline text-to-speech audio caching generates clear speech without third-party fees.

Dataset Collection Tooling

Dataset collection tooling is being prepared for the upcoming word-sign recognition phase. No real human word-sign training clips are included in Baseline v1.

5. Dataset Architecture

Fingerspelling images and landmark representations.

  • Raw Alphabet Dataset: 42,000 images across 35 classes (1,200 images per class).
  • Processed Feature Splits: 4,136 extracted 63D landmark vectors partitioned into:
    • train.npz: 2,895 samples
    • val.npz: 620 samples
    • test.npz: 621 samples
  • Label Map: data/processed/landmarks/label_map.json mapping numeric indices to character labels.

7. Team Quick Start

Instructions for running the verified baseline locally.

1. Clone the repository and checkout the team branch:

git clone https://github.com/yash249114/Indian-Sign-Language-Translation.git
cd Indian-Sign-Language-Translation
git checkout baseline-v1-team

2. Create virtual environment & install requirements:

python -m venv venv
# Windows: .\venv\Scripts\activate | Linux: source venv/bin/activate
pip install -r requirements.txt

3. Start the application:

python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000

4. Execute the automated test suite:

python -m pytest tests/ -v

9. Current Limitations

Explicit project boundaries for Baseline v1.

Subsystem Current Status Technical Reality
Isolated Fingerspelling VERIFIED Recognizes static characters A-Z and digits 1-9 accurately.
Temporal Word Signs FUTURE Dataset collection tooling is in preparation; no real human multi-signer training clips are included in Baseline v1.
Continuous Sentence Signing FUTURE Requires neutral-pose pauses between signs. Continuous sentence decoding is planned for Phase 3.
Video Search Engine FUTURE Query-based ISL video retrieval will be developed in Phase 4.
